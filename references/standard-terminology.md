## 英文名词

| 标准词汇 | 词汇释义 |
| --- | --- |
| iOS | 苹果公司开发的移动操作系统。 |
| Android | 安卓。由 Google 主导开发的开源移动操作系统。 |
| HarmonyOS | 鸿蒙操作系统。华为研发的全场景分布式操作系统，支持手机、平板、穿戴及车载等多种智能设备。 |
| PC | 个人计算机（Personal Computer）。通常指运行 Windows 或 macOS 系统的电脑。 |
| App | 移动应用软件。 |
| WebView | 移动端 App 内的浏览器组件。用于在应用内部加载并显示网页（H5）内容。 |
| iframe | 网页内联框架。用于在当前网页中嵌入另一个网页（页面套页面）。 |
| UniApp | 跨平台开发框架。支持“一套代码，多端发布”（含 iOS、Android、小程序、H5）。 |
| H5 | HTML5 的简称。泛指在移动端浏览器或 App 内运行的互动网页。 |
| SaaS | 软件即服务。通过浏览器或 App 订阅即可使用的在线软件服务。 |
| PaaS | 平台即服务。为开发者提供构建、部署应用的云端平台。 |
| aPaaS | 应用平台即服务。侧重于低代码/无代码开发，让业务人员也能快速搭建应用。 |
| API | 应用程序接口。不同软件系统之间进行通信和数据交换的桥梁。 |
| SDK | 软件开发工具包。厂商提供的功能包，开发者只需调用即可实现特定功能（如支付、地图）。 |

# 动词

| 标准词汇 | 不推荐用法 | 使用场景/含义 |
| --- | --- | --- |
| 登录 | 登陆 | \- |
| 新建 | 创建 | 从无到有新建一个对象，过程需要一系列的输入或配置，如：新建直播。 |
| 添加 | \- | 把已有对象添加到一个集合之中，如：添加标签。 |
| 编辑 | 修改 | \- |
| 删除 | \- | “永久性”地去除操作对象，包含硬删除、软删除，硬删除是从数据库彻底删除，软删除是操作界面上删除，但数据库中不删除。 |
| 移除 | 移出 | “暂时性”地去除操作对象，操作对象在当前列表中不再显示，但仍存在于系统中。 |
| 筛选 | 搜索、查询 | \- |
| 导出 | \- | 导出列表。 |
| 下载 | \- | 下载文件。 |
| 导入 | \- | 导出列表。 |
| 上传 | \- | 上传文件。 |
| 确认 | 确定 | 对某个动作进行二次确认。 |
| 请稍候 | \- | 表示“请稍微等候”，后不接动作，如：数据加载中，请稍候。 |
| 请稍后 | \- | 表示“请稍微延后”，后接动作，如：请稍后重试。 |
| 截至 | \- | 强调“时间”，一般用在时间词语之前，如：截至周五。 |
| 截止 | \- | 强调“停止”，一般用在时间词语之后，如：已于周五截止；如用在时间词语之前，需加“到”作为连接，如：截止到周五。 |
| 累计 | \- | 强调计算、统计的“结果”，如：累计成交额为三十万。 |
| 累积 | \- | 强调积累的“过程”，如：把所有门店的业绩累积起来。 |
| 开启 | \- | 从关闭到开启的状态。 |
| 应用 | \- | 在不关闭当前操作流程的前提下，使配置即时生效，比如：默认模板的应用到全部频道。 |
| 启用 | \- | 改变操作对象的状态，使其开始启动任务，比如：启用抽奖模板。 |
| 发送 | \- | 发送消息，比如：发送图片。 |
| 发布 | \- | 发布内容，比如：发布问卷。 |
| 推送 | \- | 强调把一个对象推出去，比如：推送消息、推送商品。 |
